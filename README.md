# 🎯 Game of Secret Number

Este é um jogo simples de adivinhação de números, desenvolvido como meu **primeiro projeto utilizando a linguagem de programação JavaScript**.

## 📚 Sobre o projeto

O "Game of Secret Number" foi criado durante meus estudos na plataforma [Alura](https://www.alura.com.br/), como parte prática de um curso introdutório de JavaScript. A ideia é treinar a lógica de programação, interações com o DOM e manipulação de eventos básicos no navegador.

## 🕹️ Como funciona

- O jogador deve adivinhar um número secreto entre 1 e 10.
- A cada tentativa, o jogo informa se o número inserido é maior ou menor que o número secreto.
- Ao acertar, o jogo exibe uma mensagem de parabéns e o número de tentativas realizadas.
- Um botão de "Novo jogo" permite reiniciar a partida.

- JavaScript (puro)
